微信授权 Code → Token

先走 OAuth2 授权拿到 code，再调用 /wx/check 换取用户信息与 token

1 微信授权获取 Code

授权地址：open.weixin.qq.com/connect/oauth2/authorize?appid=ww2dd5ef4513728159…
授权成功后微信会跳转到 https://gt-wx.gtrmt.cn/?code=XXXX#/，页面会尝试自动捕获这个 code。

2 或手动输入 Code / 回跳链接

粘贴完整链接时会自动提取 code= 之后的部分

    为什么“自动获取”有时候拿不到 code？
    

      浏览器读不到跨域重定向后的地址。微信授权接口会 302 跳转到
      gt-wx.gtrmt.cn，而 fetch 在浏览器里：
    

    

      1. 如果目标域没返回 CORS 头，请求直接失败；

      2. 用 redirect:'manual' 只能拿到不透明的 opaqueredirect，读不到 Location 响应头；

      3. 用 iframe 加载后，跨域也读不到 contentWindow.location。

      cmd 里的 curl 没有这些限制，所以能直接看到 302 的 Location。
    

    

      所以本页的做法是：先尽力尝试（fetch 跟随 + iframe 探测），
      失败后自动打开授权页；你在授权页完成跳转后，
      复制地址栏链接，回到本页点「从剪贴板读取」，即可自动提取 code 并换 token。
    

    
另外：微信 OAuth2 授权页在电脑浏览器中通常提示“请在微信客户端打开链接”，建议在微信内置浏览器里完成授权，或直接手动粘贴回跳链接。

    
用 curl 自测（和页面发出的换 token 请求体完全一致）：

    
curl -k -X POST "https://ali.gtrmt.cn:8895/wx/check" -H "Content-Type: application/json" -d "{\"url\":\"https://gt-wx.gtrmt.cn/?code=<CODE>#/\",\"usercode\":\"<CODE>\",\"agentid\":\"1000031\"}"
